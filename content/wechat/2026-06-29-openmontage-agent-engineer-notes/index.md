# 我用AI做了一支"唐朝兴衰史"视频，全程没写一行剪辑代码

---

## 先看效果

前几天我做了一支视频：**《唐朝兴衰史》1分钟版**。

![唐朝兴衰史 1分钟版 截图](assets/demo-tang-1min-cover.jpg)

开篇是玄武门缓缓推开，镜头推向宫殿；接着是隋末战乱的铠甲、贞观之治的长安城、武则天称帝的大殿、安史之乱的烽火……最后定格在"盛唐落幕"的卷轴上。

整支视频57秒，720p，有旁白、有配乐、有字幕、有电影级的运镜和转场。

**我没有打开过任何剪辑软件，也没有写一行剪辑代码。**

我做的事情只有一件：跟我的AI助手说，"帮我做一支关于唐朝兴衰史的讲解视频，1分钟，国潮纪录片风格"。

剩下的事情——查资料、写脚本、分镜、生成画面、配音、配乐、加字幕、做转场、渲染成片——全部由一个Agent自动完成。

支撑这一切的，是一个叫 **OpenMontage** 的开源项目。

---

## OpenMontage 到底是什么

一句话：**它是第一个真正"Agent驱动"的开源视频生产系统。**

不是那种"输一句话，出5秒短视频"的玩具。它把一个完整的视频制作团队——研究员、编剧、分镜师、素材师、剪辑师、音效师、审片人——全部装进了一个Agent里。

截至 2026 年 6 月，这个项目已经有：

- **12 条**生产管线（动画解说、纪录片、产品介绍、财报分析……）
- **57+** 个工具（TTS、图像生成、视频生成、音乐、ASR、字幕……）
- **500+** 个 Agent 技能文件
- 支持 **14 个**视频生成提供商、**10 个**图像生成提供商、**5 个**TTS 提供商
- GitHub 登上过 Trending #1，峰值日增 3400+ Star

它的核心假设很反直觉：**视频制作这种复杂工作流，最合适的编排者不是硬编码的DAG引擎，而是能读指令、理解上下文、做判断的通用Agent。**

![传统方式 vs Agent 驱动](assets/infographic-agent-vs-dag.png)

*左：传统方式靠硬编码的固定流程，改一个步骤就要改代码。右：Agent 驱动，由智能体动态选择和组合工具。*

## 它厉害在哪里

### 1. 不是"工具集合"，是"会自己选工具的系统"

普通的AI视频工具是这样的：你知道要调用哪个模型，然后一层层点按钮。

OpenMontage 是反过来的：你说"我要做一支视频"，它自己决定每一步用什么工具。

![自描述工具 + 自动评分选择](assets/infographic-tool-plugins.png)

*每个工具都有"自描述身份证"，注册表里自动收录，Agent 根据评分引擎智能选择最合适的工具组合。*

背后有一整套"工具身份证"系统——每个工具都会自报家门：我擅长什么、依赖什么、质量分多少、延迟多久、失败了用谁替补。然后有一个评分引擎，根据你的任务自动挑最合适的工具组合。

比如做唐朝视频，它会自动选：
- **画面**：Seedream 5.0（国风插画最强）+ Seedance 2.0（动态镜头）
- **旁白**：火山引擎豆包语音（中文最自然）
- **音乐**：BigMusic（古风BGM生成）
- **合成**：Remotion（纪录片级包装）

不需要你懂这些模型的区别，系统自己判断。

### 2. 不是"一次生成"，是"分阶段生产"

传统AI视频是黑箱：输入prompt → 等输出 → 不行重来。

OpenMontage 把视频生产拆成了 **8 个明确阶段**，从研究到发布，每一步都看得见、摸得着、可回退：

![八阶段生产流水线](assets/infographic-pipeline.png)

*从研究到发布，八阶段流水线。每个阶段产出明确文件，随时可中断、可修改、可恢复。*

每个阶段都会产出明确的中间文件，存在磁盘上。你随时可以介入修改，改完从当前阶段继续，不用从头再来。

做唐朝视频时，我就在"提案"阶段改了主意——本来是纯动画，我让它改成"国潮插画+实拍风动态镜头"混合风格。系统从提案阶段重跑，后面的脚本、分镜、素材全部跟着调整，前面做的研究资料完全复用。

### 3. 不是"出片就行"，是"有质量把关"

AI生成视频最大的坑不是"生成失败"，而是**"看起来成功了，其实已经降级了"**。

比如你要的是动态镜头，结果模型偷偷给你做成了"图片缓慢推拉"的幻灯片效果，不仔细看看不出来。

OpenMontage 专门有一套三层质量把关体系，像金字塔一样层层向上收敛：

![三层质量把关体系](assets/infographic-quality-gates.png)

*预算治理托底、计划阶段前置把关、渲染后做最终审查，确保"成片质量"不打折扣。*

- **幻灯片风险检测**：自动检测视频是不是"伪动态"，发现了就打回去重生成
- **交付承诺验证**：提案阶段说"要有电影级运镜"，合成后真的去检查有没有达到
- **预算治理**：你可以设成本上限，超了自动警告或停止，不会偷偷烧钱
- **渲染后审查**：出片后还有一轮自我审查，音画同步、字幕对齐、画面稳定性全查

这些把关不是事后检查，是**嵌在生产流程里的关卡**——过不了就进不了下一阶段。

### 4. 不是"只能做一种视频"，是"管线即插件"

OpenMontage 厉害的地方不是它能做多少种视频，而是**加一种新视频类型有多容易**。

想加一个"知识科普"管线？写一个 YAML 文件就行。想加一个"产品开箱"管线？再写一个 YAML。

因为整个系统的核心不是代码，而是**声明式的管线清单 + Markdown 技能文件**。Agent 读这些文件就能学会新的制作流程，工程师不用改一行编排代码。

这也是为什么社区能快速攒出 12 条管线——不是核心开发写的，是用户自己加的。

## 两个更厉害的例子

唐朝 1 分钟版只是开胃。我还用 OpenMontage 做了两支更长、更复杂的视频。

### 作品一：《蔚来2026 Q1财报分析》，纯Remotion剪辑炫技

![蔚来2026 Q1财报分析 截图](assets/demo-nio-earnings-cover.jpg)

这支视频 **2 分钟，1080p**，特点是：**完全没用任何AI视频生成模型**。

它是一支纯 Remotion 合成的财报分析视频——数据图表动画、章节卡片、数字滚动、转场特效、胶片颗粒、BGM铺底，全是代码渲染出来的。

效果是什么水平？这么说吧，发朋友圈有人问我是不是请了专业后期团队。

OpenMontage 在这里做的事情是：读财报数据 → 写分析文案 → 拆解章节 → 生成图表数据 → 调用 Remotion 组件库组装 → 渲染成片。

你不用写一行 React 代码，也不用调任何动效参数。告诉Agent"帮我分析蔚来Q1财报，做一支2分钟视频"，它就给你出片。

### 作品二：《唐朝兴衰史》5分钟版，AI生成的长纪录片

![唐朝兴衰史 5分钟版 截图](assets/demo-tang-5min-cover.jpg)

这是真正考验系统能力的作品——**整整 5 分钟，1080p**。

5 分钟的AI视频是什么概念？现在大多数 AI 视频模型一次只能生成 5-10 秒。要做出 5 分钟的片子，你需要：

- 把 5 分钟拆成几十个镜头
- 每个镜头单独生成，保持风格统一
- 镜头之间做转场，不能跳戏
- 旁白要连贯，不能一段一段接
- 音乐要铺满，情绪要有起伏
- 字幕要对齐，章节卡片要到位

这些事情，OpenMontage 的Agent全部自动完成。

它甚至会自己做"节奏设计"——开头3秒抓注意力，每章结尾留一个"重新hook"的节点，高潮部分加快剪辑节奏，结尾用慢镜头收束。

你看到的是 5 分钟的成片，背后是Agent做了上百个决策的结果。

## 普通人能用吗

老实说，现在还没到"点开网页就能用"的程度。

OpenMontage 是一个**面向开发者和高级用户**的开源项目。你需要懂一点命令行，有本地运行的AI编程助手（Claude Code、Cursor、Codex 这类），还要自己配各家API的key。

但如果你符合上面任何一个身份——

- 做内容创作，想批量出视频
- 做产品，想给产品加AI视频能力
- 做Agent开发，想研究复杂工作流的编排方式

那 OpenMontage 值得你花一个下午跑通一次。它会刷新你对"AI到底能把工作流自动化到什么程度"的认知。

项目地址：[github.com/calesthio/OpenMontage](https://github.com/calesthio/OpenMontage)

## 最后说两句

我玩过很多AI视频工具。大多数的感觉是："哇，好厉害，但也就那样。"

OpenMontage 给我的感觉不一样。它不是在"让AI生成视频"这件事上卷画质，而是在回答一个更根本的问题：**当AI能做的事情越来越多时，我们怎么组织这些能力，去完成真正复杂的工作？**

它给出的答案是：把工具做成自描述的，把流程写成声明式的，把质量把关嵌进每个阶段，然后把编排权交给Agent。

这个思路不止适用于视频制作。写作、设计、编程、研究……任何复杂工作流，都可以照这个模式重构。

视频可能只是第一个被彻底改变的领域。
