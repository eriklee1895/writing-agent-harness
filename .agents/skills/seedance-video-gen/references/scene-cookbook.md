# Seedance 2.0 场景 Cookbook

完整场景示例。先读 `key-constraints.md` 了解能力边界，提示词技巧见 `prompt-guide.md`。

## 1. 教育动画短视频

**要点**：主体清晰、动作缓慢、信息密度适中、风格一致。

```
A 2D flat vector animation of a water molecule in a clean illustration style.
The molecule gently splits into two hydrogen atoms and one oxygen atom, a small
spark connects them briefly before they separate. Clean light blue gradient
background, soft diffused lighting, locked-off eye-level medium shot, slow and
clear motion. 无字幕，无Logo，无水印，无复杂背景细节。Pastel blue and white
palette, educational and friendly mood.
```

```
A 3D Pixar-style animation of a cartoon rocket on a launch pad. Countdown
numbers appear one by one【3...2...1...】then the rocket gently lifts off with
a small puff of smoke, ascending slowly toward the top of frame. Clean dark
blue gradient sky background with scattered stars, soft diffused lighting,
locked-off medium shot, 5-second clip. 无字幕，无Logo，无水印。Warm and
encouraging mood.
```

## 2. 短剧（文戏 / 对话）

**角色锚定优先**。每个角色必须明确定义，全程使用同一标签。对话台词用 `{}` 包裹。

```
将图片1中穿米色毛衣、长直发的女孩定义为主角，图片2作为宿舍场景风格参考，
参考视频1的运镜方式。

镜头1：傍晚，主角脚步轻快地走到宿舍门口，镜头中景平稳跟拍，暖黄色日光从窗外
洒进走廊，她在门口停顿，深呼吸，表情略带紧张。
镜头2：主角推开门走进宿舍，镜头切到室内中景，舍友一边整理书本一边抬头看向她，
其中一人笑着问{考得怎么样呀，过了吗}，镜头在几人之间缓慢切换半身特写。
镜头3：主角先低头露出落寞表情，镜头给到她的近景，随后她抬头憋不住笑意，
哈哈大笑说{骗你们的}，舍友们追着打闹起来，镜头缓慢拉远，定格在宿舍内一片
欢声笑语的全景画面。

全程画面高清电影纪实风，色调温暖，光影柔和；人物面部稳定不变形，动作自然流畅，
无卡顿无闪烁。
```

## 3. 短剧（动作 / 氛围）

```
镜头1：黄昏，悬崖边的古松旁，白衣剑客缓缓收剑入鞘，衣袂被山风吹起，
镜头从低角度缓慢升起，远处的云海翻涌。背景中播放着悠远的古琴乐。
镜头2：黑衣剑客从松树后走出，两人对视，中景，固定机位，风卷起松针在两人之间
飘过。黑衣剑客说{你终究还是来了}。
镜头3：白衣剑客微微低头，嘴角浮现一丝苦笑，镜头缓慢推近到特写，他说
{有些事，总要有个了断}。

全程 3D 国风 CG 仙侠风格，冷色调，低饱和度，人物面部稳定不变形，无字幕。
```

## 6. 首帧图生视频

```
以提供的首帧图作为起始画面：卡通火箭缓慢点火，白色烟雾从底部喷出，火箭
开始微微震动然后离开地面向上升起，从画面底部逐渐向中间移动。
保持相同的扁平 2D 插画风格和粉彩色调。镜头固定机位，5 秒，平滑过渡，无突变。
```

## 7. 首尾帧图生视频

```
从首帧平滑过渡到尾帧。首帧是一本合上的旧书，尾帧是同一本书翻开、书页轻轻翻动。
镜头缓慢环绕书本 180 度，书页在移动中自然翻开。温暖的午后阳光从窗口照入，
保持一致的复古胶片风格和暖色调。5 秒，无突然跳变。
```

## 8. 多模态参考

```
使用图片1作为角色风格参考，视频1作为运镜参考，音频1作为背景音乐。
角色在一条阳光斑驳的森林小径上行走，匹配视频1中缓慢的跟拍运镜。
无文字，无人脸，平滑运动，5 秒。
```

## 9. 文字生成场景

### 广告语

```
手绘漫画风格，三个人围坐在一起吃图片1中的炸鸡，气氛友好愉悦，
后画面逐渐模糊，画面中部显示文字"快乐尽在 Seedance"。
```

### 对话字幕

```
生成带有画外音的视频。一个深沉平静的男声说："在宏大的宇宙中，我们的世界不过是
一个短暂的瞬间。然而，在其中，生命不顾一切地繁荣。"场景从夜晚缓慢过渡到黎明，
星星逐渐消失，太阳从山后升起。画面底部按照台词出现字幕。
```

### 对话气泡

```
图片1中的两人穿着运动服在操场跑步，女孩看向男孩，自信地笑着说：
{We can definitely do it!} 镜头切到男孩近景，他犹豫地回答：{Are you sure?}
镜头切回女孩中近景，她语气轻快地说：{Yes!} 情绪明亮而坚定。
说话的角色周边出现气泡，气泡里是对应台词。
```

## 10. 视频编辑（增删改）

### 增加元素

```
在视频1的台面上添加炸鸡、披萨等小吃。
```

### 删除元素

```
清除视频1桌面上的其他零件和工具，保持桌面整洁干净，桌面上只有他俩手里的工具。
```

### 修改元素

```
将视频1礼盒中的香水替换成图片1中的面霜，运镜不变。
```

## 11. 视频延长 / 轨道补齐

### 向后延长

```
生成视频1之后的内容，迟到的两个男士跑向他们，五个人终于见面，友好聊天。
```

### 向前延长

```
向前延长视频1，给白衣男子过肩镜头，白衣男子说：{It's not that bad. You're
just stressed. Everyone goes through this, you just need to keep going.}
```

### 轨道补齐

```
视频1，树叶落地的瞬间，激起金色粒子特效，一阵风吹过，接视频2。
```
