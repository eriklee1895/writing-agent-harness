# Seedream 提示词工程指南

## 通用公式

### 基础公式

```
[风格锚点] + [主体 + 行为 + 环境] + [细节元素] + [色彩 + 光影 + 构图] + [分辨率/比例]
```

### 进阶公式（社区推荐）

```
风格定调 → 主体聚焦 → 场景构建 → 细节封神
```

## 最佳实践

### 1. 把提示词当成"画师需求说明书"

描述你想要什么，就像告诉画师要画什么：先说主体和行为，再说环境和氛围，最后指定风格和技术参数。

### 2. 风格锚点放开头

用一个单一、明确的主导风格标签开头：

✅ 好：
> "超写实风格，一只橘猫坐在江南古镇的青石板路上，黄昏蓝调时刻，灯笼暖红光斑在猫毛发上晃动"

❌ 差：
> "一只猫在古镇上，超写实但有点水墨画感觉，赛博朋克元素"

### 3. 使用具象文化名词

种子模型（Seedream）对中文文化名词有专门映射库。用具体名词，不要用抽象形容词：

| 抽象（❌） | 具象（✅） |
|-----------|----------|
| 古建筑 | 白墙黑瓦的徽派建筑 |
| 中国风 | 飞檐翘角的中式亭台楼阁 |
| 水乡 | 石桥横跨清澈河面，乌篷船缓缓划过 |
| 传统颜色 | 佛头青、霁红釉 |

### 4. 文字内容用引号包裹

画面中需要出现文字时，用中文引号""包裹：

> "生成一张海报，标题为"AI时代的内容创作"，副标题为"从工具到创造力""

### 5. 控制负面 prompt（不要的内容）

使用自然语言的排除：
> "不要人物"、"不要文字"、"无模糊"、"无杂乱背景"

### 6. 比例/尺寸的自然表达

可以直接说用途，模型会推断比例：
> "适合手机竖屏壁纸"、"适合微信公众号头条封面"、"适合16:9电脑桌面"

## 组图/批量生成技巧

### 触发组图模式的关键词

> "生成一组"、"一系列"、"组图"、"帮我生成几张图"、"生成4张连贯"

### 分镜/故事板模式

Seedream 4.0+ 支持三种模式：

| 模式 | 关键词 | 适用场景 |
|------|--------|---------|
| 自动 | `sequential_image_generation: auto` | 通用组图 |
| 故事书 | "故事书模式，角色特征保持一致" | 叙事/绘本 |
| 连环画 | "连环画风格，4格漫画布局" | 漫画/分镜 |

分镜 prompt 要点：
- 明确每个场景的景别（特写/中景/远景）
- 保持角色一致性：`"保持图1的角色形象"`
- 指定氛围/情绪变化

### 参考图风格跟随

> `"参考图3的风格进行生成"` 或 `"将图1的角色放入图2的背景中"`

## 中文提示词常见误区

### ❌ 误区 1：用抽象形容词堆砌

> "唯美、梦幻、高级感的风景"

✅ 改正：描述具体的视觉元素
> "江南水乡诗意画卷，白墙黑瓦古建筑，晨雾缭绕，水面倒映天空"

### ❌ 误区 2：无风格锚点

> "一只猫在花园里"

✅ 改正：先锁定风格
> "宫崎骏风格，童话花园中一只三花猫趴在石阶上，阳光透过树叶洒下斑驳光影"

### ❌ 误区 3：多风格混合

> "赛博朋克+水墨中国风+梵高印象派"

✅ 改正：选一个主导风格
> "赛博朋克风格，未来城市高楼布满电子屏与霓虹，飞行汽车穿梭，霓虹灯光闪烁，雨滴在玻璃上滑落"

### ❌ 误区 4：无分辨率和比例

> 纯 prompt 内容，没有 `size` 或比例描述。

✅ 改正：显式指定或描述
> 末尾加 `--size 2K` 或 prompt 中写"适合16:9横版构图"

## API 调用最佳实践

1. **生图前先用 `--dry-run`** 检查请求体，确保参数正确。
2. **prompt 长度**：中文推荐 ≤300 字，英文 ≤600 词。超长可能被截断。
3. **参考图**：本地文件自动转 base64 上传，URL 直接透传。
4. **web_search** 默认开启，对于时效性/知识性 prompt 效果好；纯抽象创作可用 `--no-web-search` 关闭。
5. **size 选择**：`2K` 直出（快），`4K` AI 增强（细节多但慢）。官网标注 2K 为原生输出，4K 为 AI 增强。
