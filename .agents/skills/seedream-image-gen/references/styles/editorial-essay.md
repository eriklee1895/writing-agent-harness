# 散文/随笔/文艺评论风格

适合：散文、随笔、文化评论、城市记忆、自然写作、旅行文学、个人叙事的文章配图。

本 preset 提供的是**脚手架而非模具**：它默认使用诗意、氛围感强的编辑式图像，但当用户 brief 已经带有强烈视觉概念时，模型应只保留结构 guardrails（无图表元素、以视觉隐喻为主），让出风格自由。

## 结构模板（除非 brief 覆盖，否则保留）

| Guardrail | 默认 Prompt 关键词 |
|---|---|
| 媒介 | `当代编辑插画`, `印象派风格`, `中国古风写意`, `江南水乡画卷`, `静物插画` |
| 背景 | `柔和或纯色背景`, `大面积留白`, `无图表元素` |
| 构图 | `视觉隐喻`, `层次丰富`, `中心象征物或场景` |
| 硬约束 | `无logo`, `无UI截图`, `无对话气泡除非漫画/拼贴风`, `无箭头/流程图元素除非brief要求`, `除非用户要求否则避免纯照片写实` |

## 灵感默认（当 brief 自带风格/氛围/配色时可被覆盖）

| 子风格 | 默认方向 |
|---|---|
| 印象派诗意 | `柔和笔触`, `光影变幻`, `安静氛围`, `色彩细腻`, `油画质感` |
| 中国古风写意 | `水墨晕染`, `大面积留白`, `东方意境`, `墨色层次` |
| 江南水乡诗意 | `白墙黑瓦`, `石桥流水`, `水墨画/电影感摄影`, `Seedream 中文地域风格强项` |
| 杂志编辑风 | `节制色调`, `纹理感`, `电影感偏蓝调色`, `现代生活隐喻` |

> **覆盖规则：** 如果用户指定了不同的画派、配色或氛围，就放弃灵感默认，只保留结构模板（编辑式/隐喻构图、无图表元素、硬约束）。

## 1. 印象派诗意

柔和的笔触、光影变幻、放松的氛围感。适合自然/记忆/慢生活随笔。

**核心公式**:
```
印象派风格，[自然场景]，[光线描述]，[细节元素]，笔触轻松，色彩细腻，气氛安静
```

**示例（完整 preset）**:
```
印象派风格，阳光花园中花朵绽放，光影变幻，远处有白色长椅，蝴蝶纷飞，笔触轻松，色彩细腻，油画质感，16:9
```

```
印象派风格，秋日黄昏的公园长椅，落叶满地，金色光线穿过树梢，两个模糊的人影在远处散步，温暖怀旧的氛围，4K
```

**适用场景**: 自然随笔、季节记忆、慢生活、内在感受

## 2. 中国古风写意

水墨晕染、大面积留白、东方意境。适合文化/历史/文旅/传统题材。

**核心公式**:
```
中国古风写意，[山水/建筑/场景]，[水墨/色彩描述]，留白，意境深远，[细节元素]
```

**示例（完整 preset）**:
```
中国古风写意，连绵山峦云雾缭绕，瀑布飞泻，山脚有湖，湖边亭台楼阁，小船摇曳，墨色层次丰富，晕染自然，4K
```

```
写意山水，大面积留白，远山淡影，孤舟一叶，墨色由浓渐淡，营造极简东方意境，16:9
```

**适用场景**: 传统文化、历史叙事、哲学思考、东方美学

## 3. 江南水乡诗意

Seedream 对中文地域文化有专门词汇映射，白墙黑瓦、石桥流水、桃花等关键词触发高质量输出。适合地域/家乡/季节主题。

**核心公式**:
```
江南水乡诗意画卷，[建筑/水的描述]，[季节/光线]，[细节元素]，水墨画/高清摄影风格
```

**示例（完整 preset）**:
```
江南水乡诗意画卷，白墙黑瓦古建筑，石桥横跨清澈河面，乌篷船缓缓划过，岸边盛开桃花，水墨画风格，4K，16:9
```

```
江南冬日清晨，薄雾笼罩河面，白墙黑瓦的民居沿河排列，石板路上行人稀少，灯笼微亮，安静而清冷，电影感摄影风格，16:9
```

**适用场景**: 地域文化、家乡记忆、季节散文、文旅

## 4. 杂志编辑风

当代编辑插画、层次构图、节制色调、文章友好的视觉隐喻。适合文化评论/观点文/思想散文。Seedream 5.0 Pro 在 2K 下可稳定渲染大字号杂志标题/kicker overlay（逐字写进 prompt 并用引号包裹，指定 bold serif / sans-serif），但无字版本仍然是散文/随笔头图的默认安全选择。

**核心公式**:
```
当代编辑插画，[视觉隐喻]，层次丰富的构图，节制色调，气氛感强但具象，无图表无箭头[；可选：画面顶部/左下叠加大号标题文字"[标题]"，bold serif 字体，与画面色调协调]
```

**示例（完整 preset）**:
```
当代编辑插画，一只纸船航行在旧书页组成的海洋上，远处是灯塔，节制色调，柔和的自然光，纹理感，隐喻探索与知识，无图表无箭头，4K
```

```
编辑插画风格，城市天台上一人独坐，俯瞰万家灯火，冬日夜空，冷色调与暖色灯光对比，电影感偏蓝调色，画面左下角叠加大号白色衬线标题"冬夜", 16:9, 2K
```

**适用场景**: 文化评论、观点文、现代生活、独处/探索主题

## 散文随笔图通用技巧

1. **先给情绪，再给事实。** 散文配图应"像"文章，而不是解释文章。
2. **多用视觉隐喻。** 纸船、空椅、开窗、灯塔——把抽象名词变成具体画面。
3. **文字可选而非禁用。** 大部分散文插图无字更佳；但杂志编辑风在 2K Pro 下可叠加大字号短标题/kicker，逐字写进 prompt 并用引号包裹，指定 bold serif / sans-serif 字体，标题字数控制在 2-6 字。长段正文、诗句多行排版仍需后期叠加。
4. **头图推荐 `16:9` 或 `4K`；** 内文小图可用 `1:1`；含文字 overlay 优先 `2K`。
5. **中文散文可大胆用古风/江南意象。** Seedream 在这类中文诗意描述上表现突出。
6. **当用户 brief 已自带画派、配色或氛围时，放弃灵感默认，只保留结构 guardrails。**
