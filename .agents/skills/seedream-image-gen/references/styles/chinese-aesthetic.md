# 中式国风 / 节气节日 (Chinese Aesthetic)

> 这是 Seedream 5.0 Pro 的**强势风格区**——字节跳动原生中文训练语料对国风意象、二十四节气物候、书法字体、传统器物与中式配色映射深度好，节气海报、新中式封面、水墨写意、国潮商业图在 Pro 下出图质量高，不容易出现"日式中国风""中西混搭"的违和感。Lite 仍可使用本 preset 出概念稿，但工笔细节、书法飞白、印章篆字、瓷器纹样会明显发糊或张冠李戴，正式交付一律 2K Pro 起步。

适合：二十四节气海报、春节/中秋/端午/元宵节日视觉、新中式杂志封面、国潮商业设计、水墨写意山水、工笔花鸟、中式建筑/园林/古镇、中式美食（月饼/粽子/汤圆/茶）、书法大字标题、博物馆文创。

## 结构 Guardrails（所有中式国风图通用）

### 1. 配色体系 —— 按场景选色，不要乱混

| 场景 | 主色 | 点缀色 | 禁忌 |
|---|---|---|---|
| 立春/春分（春始） | 嫩绿 `#A4C49A` + 柳黄 `#E8D98A` + 雨雾灰白 `#E8E4DD` | 杏粉 `#F2C6C2`、燕子墨黑 | 不要秋黄/冬白主调；不要浓艳 |
| 大暑/夏至（盛夏） | 浓绿 `#2E5C3F` + 荷青 + 天空青蓝 `#6FA8BD` | 荷粉 `#E89BAE`、西瓜红、冰白、日炙橙 `#E87A4F` | 不要秋冬暖色主调；饱和度可略高 |
| 秋分/中秋（秋节） | 金黄 `#D4A24C` + 深夜靛蓝 `#2C3E5C` + 稻米色 `#EDE0C2` | 桂黄、枫红 `#B84A3A`、月白 | 中秋是圆月非弯月；不要大面积朱红 |
| 大雪/冬至（寒冬） | 冷白 `#F4F6F8` + 雪蓝 `#BCCEDC` + 墨黑 `#2A2D33` | 腊梅朱红 `#B83A30`（灯笼/梅花一点暖） | 不要大面积朱红/金黄；冷底暖点睛 |
| 清明/寒食 | 烟青 + 浅灰 + 嫩绿 + 雨白 | 柳色、白色梨花 | 不要浓艳；不要喜庆元素（无红灯笼/红福字）|
| 端午 | 墨绿 `#2E4600` + 雄黄/朱红绳结 | 粽叶棕、艾草绿 | 不要圆月/玉兔/月饼（那是中秋）；不要雪景 |

| 水墨写意 | 墨分五色（焦/浓/重/淡/清）+ 宣纸米白 `#F5EFE0` | 朱砂印章红 `#B83A30` 一点、花青 `#3C5E6E` 极淡 | 不要彩色；不要高饱和 |
| 工笔重彩/花鸟 | 绢本米黄/古绢底色 + 矿物色（石青 `#2E5984` / 石绿 `#5A8C5A` / 朱砂 / 藤黄 `#E8B94A` / 胭脂 / 蛤白） | 墨线勾边 | 不要水彩晕染感；色块平涂勾线 |
| 新中式杂志/生活方式 | 米白/亚麻 `#F2EAD8` + 墨黑 | 单色点缀（朱红/石青/松绿，只选 1 个） | 避免龙凤祥云麒麟等"皇家/节庆符号堆砌" |
| 国潮商业 | 青绿山水（石青 `#2A9D8F` + 石绿 `#264653`）+ 朱红 + 金 + 米白 | 现代产品色（科技蓝/品牌 VI 色） | 主色 ≤3，避免色盘过杂 |

### 2. 书法字体族 —— 用族名，不要写字体文件名

| 场景 | 推荐 font family 描述 |
|---|---|
| 大标题/节气名/书名/节日名 | `粗宋体`（庄重）/ `颜体楷书`（雄浑）/ `魏碑`（古拙）/ `瘦金体`（锐利雅致，宋徽宗风）/ `隶书`（古朴厚重）|
| 书法艺术海报/单字艺术 | `行书`（王羲之/米芾风，流畅飘逸）/ `草书`（仅限 1-2 字大字）/ `手写毛笔字`（率性写意，带飞白）|
| 副标题/小字题款/竖排诗句 | `小楷` / `仿宋` / `瘦金体小字` |
| 现代新中式/杂志封面 | `细宋体` / `现代无衬线中文字体`（偏现代感） |
| 英文搭配 | `serif (Bodoni-style)` / `geometric sans-serif` |
| 印章 | `红色篆刻印章` / `朱文印章`（阳刻，红字白底）/ `白文印章`（阴刻，白字红底）——方形/随形章，大小占画面 3-5%，位置题款下方或左下/右下"压角" |

**禁止写法**：`思源宋体` / `方正兰亭` / `汉仪粗黑` / `Helvetica Neue` 等具体文件名——模型不认识，会退回默认字体。

**文字可靠性（国风版）**：
- 大字（单字 - 8 字）、书法大字、印章篆字：2K Pro 下可靠，逐字用「」引号包裹。
- 诗句一联（7-14 字）：多数正确，偶有笔画变形/同音字替换，重试一次。
- 竖排长诗/古文段落/题跋（>14 字）：错字累积，**后期 PS/Figma 加字**。
- 狂草/草书多字（>4 字）：笔画糊成团，只适合单字大字（「福」「龙」「禅」「静」）。

### 3. 构图章法 —— 中式美学不是西式满构图

- **留白是灵魂**：四周至少 15-25% 空白；山水/禅意场景留白可占 40%+；显式写 `大面积留白` / `右上/左侧留 30% 留白` / `留白透气`。
- **散点透视**，不是西方焦点透视——山水/长卷场景写 `散点透视、多点观察、中国传统山水画构图、非西方焦点透视`。
- **疏密对比**：`疏可跑马、密不透风`——主体区域刻画细密（花、石、建筑），其余留白或淡墨晕染。
- **主体偏侧不居中**：主角（花枝/孤舟/月亮/太湖石）偏左或偏右，留白处放题款和印章；对称构图只用于春节/宫廷/正式喜庆场景。
- **印章补角**：国画/水墨/节气海报通常右上或左上留白处竖排题款，题款下方或对角压角钤 1-2 方红色印章平衡视觉。
- **三层景**：近景（浓墨/清晰/笔触重）→ 中景（主元素）→ 远景（淡墨/虚化/云雾）。
- **元素克制**：一张图 1-2 个主元素（梅+雪、鹤+云、月+桂、舟+江）——红灯笼+龙+凤+祥云+梅花+锦鲤+青花瓷+京剧脸谱一锅粥是国潮审美的反面教材。
- **意境 > 写实**：水墨、工笔、节气都是"意境感"不是照片写实（除国潮商业产品图外）。

### 4. 文化准确性硬约束（张冠李戴会翻车）

- **节日物候要对得上**：
  - 春节→红灯笼/对联/福字/烟花/鞭炮/生肖/红包（白灯笼是丧事，禁用）。
  - 中秋→圆月（非弯月）/桂花/玉兔/月饼/深蓝夜空；不要红色主调。
  - 清明→春雨/柳/杏花/燕子/烟雨白墙；不要喜庆红色元素。
  - 端午→龙舟/粽子/艾草/五色绳/雄黄/菖蒲；不要圆月/月饼/玉兔。
- **建筑形制**：徽派是白墙黑瓦马头墙；江南水乡是石拱桥+乌篷船；故宫是红墙黄瓦；苏州园林是白墙+假山+漏窗；笼统说"中式古建筑屋檐一角"比指定朝代安全。
- **朝代感要统一**：唐（丰腴华丽/三彩/斗拱硕大出檐远）；宋（极简素雅/汝窑天青/青瓷/白瓷/建盏）；明（家具极简线条/紫砂兴起/文人园林）；清（繁复雕花/珐琅彩/粉彩）——prompt 涉及古器物/家具/服饰时最好带朝代词，不要混搭。
- **龙凤祥云不是万用装饰**：龙/凤/五爪金龙/明黄色是皇家/大典/婚庆专用，不要随便加在禅意茶道/文人山水/日常新中式；日常场景用 `卷云纹` / `如意纹` / `回纹` 更安全。
- **祥云纹样**：中式祥云是如意云头（卷云头），不是西方棉花糖云朵——写 `中式卷云纹` 不要写 `祥云` 后就不管。
- **服饰形制**：若出现人物，写 `汉服` / `中式传统服饰` 或笼统 `长袍` 最安全；具体款式（曲裾/齐胸襦裙/马面裙/褙子）容易形制错误（右衽方向、袖型、配色制度），节气海报建议**以景为主、人物剪影/背影点缀**最稳。
- **显式写"中式"**：写 `东方风` / `亚洲风` 可能出日式（鸟居/和服/浮世绘）——**必须写"中式""中国风""国画""国风""新中式"**。

### 5. 尺寸与比例 —— 默认 2K，竖版优先

- 默认 `--size 2K`（1536×2048 竖版 3:4；书法笔触/印章/纹样在 1K 下发糊，统一用 2K）。
- **竖版 3:4**（默认）：social cover、竖版 poster（公众号/小红书/Instagram 笔记封面、节气海报、节日贺卡、新中式杂志封面）首选。
- **横版 16:9**：`--wide` = 1792×1024（Pro 专属 shortcut；`--wechat-header` 是同尺寸别名），用于 blog hero / 视频封面 / PPT 封面 / 公众号首图 / 品牌 banner。
- **方图 1:1**（`--square`）：social posts（朋友圈/微博/小红书/Instagram 节日配图、品牌社媒氛围图）。
- **宽幅长卷**：`--size "2048x1024"` 或 `--size "2560x1080"`，用于水墨山水长卷、横版叙事画。

### 6. AI 瑕疵规避关键词（按需追加到 prompt 末尾）

- 书法字：`笔触清晰、墨色浓淡分明、字迹准确无误、无错字漏字、每个字都可辨认`
- 印章：`印章边缘有自然残缺（金石感）、印泥颜色纯正朱红、非现代印刷体、非电脑字库字体`
- 器物：`器物造型准确、釉色温润、无现代工业品塑料感、无扭曲变形`
- 古建：`建筑形制准确、无现代建筑穿帮、无电线杆无汽车无路灯无空调外机（除非场景明确要求）`
- 通用：`无水印、无乱码文字、无平台 logo、无二维码`
- 纯物景 banner：可加 `--no-negative-prompt` 放开默认"多余肢体"负面限制。

## Recipes

所有 recipe 默认 Pro 模型、2K 输出。节气海报默认 `--size 2K`（3:4 竖版）；横版用 `--wide`（1792×1024，`--wechat-header` 别名）。文字（节气名/节日名/福字/题款）**必须逐字用中文引号「」包裹**，并指定字体族、字号占比、位置、颜色、对齐；单条文字 ≤8 字最稳，参考 `text-poster.md` 的文字翻车清单。

### Recipe 1：立春 / 清明 · 春季节气海报（嫩绿 + 春雨 + 柳枝 + 燕子）

```bash
uv run scripts/seedream_image_gen.py generate \
  --size 2K \
  --prompt "二十四节气立春海报，竖版 3:4，中式淡彩插画风格。画面中下部一枝嫩绿柳树枝条从左侧斜伸入画（柳叶新绿嫩黄 #A4C49A、柳丝轻柔下垂、柳芽初绽），柳枝上方两只黑色燕子斜飞掠过（燕子造型准确、姿态灵动、燕尾分叉清晰），画面下方露出淡墨晕染的江南黑瓦屋檐一角，天空飘着细密春雨（雨丝斜向、朦胧、水汽感），远景是淡青色云雾山峦隐约可见；整体色调嫩绿 #A4C49A 与春雨灰白 #E8E4DD 为主、柳黄 #E8D98A 和杏粉 #F2C6C2 极淡点缀；右上留白占 40%，留白处竖排两个大号手写毛笔字「立春」（字色墨黑、笔触苍劲带飞白、从上到下排列、字号占画面高度 1/5、字迹准确无错字），大字下方钤一方 3% 大小的红色朱文小印章（金石感边缘自然残缺）。春意温润清新、大面积留白透气、意境清雅、中式插画非照片写实、笔触清晰、无水印无乱码文字、无现代元素穿帮、印刷质感锐利，2K"
```

- 清明变体：把主色换成更清冷的烟青/灰白+浅绿，元素加白墙黑瓦一角/白色杏花枝/牧童骑牛背影/纸伞、整体烟雨朦胧感更强，主标题改「清明」，饱和度再降一档。
- 春分变体：油菜花田金黄+粉桃、远景纸鸢飘飞、儿童剪影背影。
- 适合：seasonal marketing、茶室/书店节气海报、social 节气内容（公众号节气专栏、小红书/Instagram 节气笔记封面、品牌节气营销）。

### Recipe 2：大暑 / 夏至 · 夏季节气海报（浓绿 + 蝉 + 西瓜 + 阳伞）

```bash
uv run scripts/seedream_image_gen.py generate \
  --size 2K \
  --prompt "二十四节气大暑海报，竖版 3:4，新中式工笔淡彩插画风格。画面下半是一片浓绿 #2E5C3F 夏日荷塘（荷叶茂盛铺满水面、叶脉清晰、荷叶上有晶莹露珠），中央一朵粉荷 #E89BAE 半开、荷瓣细腻，近处一片大荷叶上蹲着一只翠绿夏蝉（蝉翼透明、造型准确）；荷塘边竹席上摆放几块切开的红瓤西瓜（瓜瓤鲜红饱满、瓜子黑色、瓜皮绿白条纹清晰）、西瓜旁有一碗琥珀色凉茶；画面右侧一把淡蓝青色中式油纸阳伞斜斜撑开（伞下半遮）；背景是盛夏正午天空（日炙橙 #E87A4F 到天青蓝 #6FA8BD 的渐变）、阳光透过树叶洒下斑驳光影。整体色彩饱和度较高、夏日炎热但有清凉感。左上留白 20% 处竖排两个大号颜体楷书字「大暑」（字色墨黑、端正雄浑、字号占画面高度 1/5、字迹准确无错字），字旁钤一方红色小印章。构图疏密对比（荷叶茂密与天空留白）、夏日氛围浓厚、笔触清晰、字迹准确、无现代物品穿帮、无水印、2K"
```

## 翻车提醒（这些场景 AI 仍做不好）

1. **名人书法临摹几乎必翻车。** 指定"仿王羲之《兰亭序》""仿颜真卿《祭侄稿》""仿启功体""仿毛泽东书法"等具体名家字迹时，模型只能出"大概像那个风格"的毛笔字，**无法**精准复刻具体字帖的字形、章法、气韵——做概念参考可以，做书法临摹字帖、书法衍生品、文化礼品图不要用 AI，用真迹扫描或书家手写。
2. **古文长段正文、竖排长诗不要让模型生成。** 4-8 字大字标题（节气名/节日名/成语/单字）成功率高；一联诗句（7-14 字）多数正确但偶有错字；**超过 14 字的竖排古诗、长段古文题跋、多行落款错字率陡增**，会出现同音字替换、笔画缺失、语序错乱、简繁混杂——诗文正文、题跋、序文一律后期 PS/Figma 用真实字体叠加。
3. **精细古代建筑测绘级细节不可靠。** 斗拱具体几铺几跳、鸱吻走兽的准确形制和数量、雀替/藻井/隔扇门的具体纹样、彩画的和玺/旋子/苏式等级制度，模型会自由发挥、张冠李戴（清代样式放到唐代建筑、明式斗拱配清式琉璃瓦）。做文旅宣传氛围图可以，做古建复原图、建筑科普测绘图、文物保护资料图不行。
4. **精细古代服饰形制容易出错。** 汉服具体款式（曲裾/直裾/齐胸襦裙/马面裙/褙子/道袍）的版型、右衽方向、袖型（广袖/琵琶袖/箭袖）、裙门数量、配色制度模型常会错乱（比如把左衽给汉人、把清代旗装扣子扣法给到明制汉服）——节气海报用"人物背影/远景剪影"或笼统"中式长袍"最安全；汉服品牌商用图必须人工审版。
5. **瓷器款识 / 青铜器铭文 / 印章篆字不可信。** 底部落款"大明宣德年制""大清乾隆年制"等款识字形模型会造字；青铜器铭文（金文/甲骨文）不可能准确；印章里的篆字经常乱造（训练集里篆刻文字有限）——做古董/文物/拍卖类图必须实拍+后期修图；要精确印章内容（名字章/斋馆章）后期用字体排版加。
6. **多人物叙事场景容易"时代穿越"。** 一个画面里同时出现不同朝代服饰/器物/建筑时（唐代街景出现明式椅子、宋代书房出现青花瓷），模型很难自控——多人物古风叙事画建议做概念草图和分镜参考，最终成片找画师人工绘制。
7. **历史人物肖像不准。** 李白/杜甫/苏轼/杨贵妃/孔子/诸葛亮等历史人物没有可靠影像存世，AI 生成的是"大众印象脸谱"（长须老者/丰满美人/羽扇纶巾的刻板印象），不是真实样貌——做历史人物传记、教科书、博物馆展览类配图需注明"AI 想象图"或使用标准造像/古画版本。
8. **国画材质/画派细分有时混淆。** 写意与工笔、绢本与纸本、水墨与青绿山水、院体画与文人画、北宗与南宗，模型偶尔会把不同朝代/画派特征混在一起——专业艺术评论、美术馆展览级别的配图，prompt 里尽量多带具体朝代+画家+作品名做风格锚点（`仿北宋范宽《溪山行旅图》风格`、`仿宋徽宗赵佶工笔花鸟`）可提升准确度，但仍需人工审核。
9. **龙鳞凤羽等复杂纹样 1K 糊。** 龙/凤/麒麟等复杂神兽的鳞甲、羽毛、龙须细节在 1K 下糊成团，**必须 2K 起步**；即便 2K 下也建议龙/凤做"半隐于云雾"式处理，不要大特写全身鳞爪毕现。
10. **"东方风""亚洲风"陷阱。** prompt 里写"东方""亚洲"可能出日式元素（鸟居/和服/浮世绘/樱花/富士山）——**必须显式写"中式""中国风""国画""国风""新中式"**，不要偷懒写"东方美学"。
