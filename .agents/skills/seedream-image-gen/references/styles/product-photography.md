# 产品/电商/美食摄影 (Product & E-commerce)

适合：e-commerce main product shots (Taobao/JD/TikTok Shop/Amazon/Shopify/etc.), social product posts (小红书/Instagram/TikTok/微博/微信带货), blog/官网 hero, 3C 数码、美妆护肤、服饰 lookbook、食品/茶饮/美食摄影、品牌详情页 hero 图、节日大促 sale banners。

这是 Seedream 5.0 Pro 的训练甜区——字节跳动本身是广告平台，产品/电商/美食摄影的 prompt 词汇映射非常成熟。Pro 单张 ¥0.30–0.60，批量迭代（同一款产品换角度、换背景、换光线 10–20 张）成本可控，且 2K 下商品标签文字（价格牌、品名、促销 tag、品牌 logo 文字）渲染准确度明显高于同价位模型，是电商素材草稿、A/B 主图、social product posts 的高性价比选择。

Lite 不推荐用于商品图：材质质感（金属反光、丝绸纹理、玻璃折射）和文字稳定性明显下降。

## 结构 Guardrails（除非 brief 覆盖，否则保留）

- **背景约定**
  - 白底主图：`纯白背景 #FFFFFF`、底部柔和投影、无杂物、无反光板穿帮
  - 场景图：符合产品使用场景的 lifestyle 背景（办公桌、梳妆台、厨房、通勤包一角等），背景虚化控制景深
  - 美食：深色木质桌面 / 大理石台面 / 亚麻餐布 / 竹席茶盘，点缀餐具/香草/餐巾/原料散落
- **光线 setup（显式指定一种）**
  - `柔和自然光 / 自然窗光`（万能安全牌，美食、生活方式首选）
  - `影棚硬光`（金属/3C 质感、轮廓分明）
  - `影棚柔光（左右双灯 + 顶部补光）`（白底主图标准）
  - `窗边侧光`（体积感强、阴影自然，3C/美妆场景常用）
  - `背光轮廓光`（透明/玻璃/发丝分离、茶器水汽逆光）
  - `暖黄餐灯光`（美食氛围感、中式点心、晚餐场景）
- **构图视角**
  - `产品居中、正前方 0°`：白底主图标准角度
  - `45° 俯视`：最常用，立体感最强，电商通用万能角度
  - `top-down 平铺（俯拍 90°）`：美食摆盘、服饰 flat-lay
  - `微距特写`：材质、纹理、logo、膏体、水珠细节
- **商品标签文字规则**：若含品牌名/价格/slogan，**必须逐字写进 prompt 并用引号包裹**，指定 `bold sans-serif`（中文 `粗黑无衬线` 或 `粗宋体`），单条 ≤8 字符，位置用相对描述（`左上角红色角标`、`产品正下方`）。长段详情文案、成分表、多行卖点后期叠加，不要让模型生成。
- **主角地位**：产品为绝对主角，占画面 60–75%；模特/道具/背景仅作氛围衬托，不喧宾夺主。道具建议只"露一角"，背景虚化。
- **AI 瑕疵规避关键词（按场景加）**
  - 通用：`产品几何形状准确，无扭曲变形，无水印，无乱码文字，瓶身/包装/表面无品牌文字、无标签、无 logo、无印刷、纯净裸瓶`
  - **瓶身/包装/曲面防乱码**：所有护肤品/香水/酒水/饮料/化妆品瓶、耳机充电盒、口红管、家电面板，**必须显式加** `瓶身无品牌文字、无标签、无 logo、无印刷文字、纯净裸瓶/裸盒/纯色素面`（Seedream 爱在曲面产品表面造假品牌名，详见 prompt-engineering.md 反模式 3）
  - 手模：`手指自然，无多指畸形，无手指融合`；能不露手就不露手（道具支撑、产品 45° 自行站立、模特揣兜/背影）
  - 反射物体：`反射合理，无穿帮倒影，反射面内容为模糊虚化的环境光`
  - 美食：`食物造型真实自然，不像塑料模型`
  - 水珠/液体：`水珠形态自然，不凭空漂浮，不悬浮，附着于物体表面`
  - 玻璃/液体：`玻璃折射真实合理，但不追求复杂内部反射`
  - 白底图：`纯白背景 #FFFFFF、背景色值准确统一、无暗角、无渐变`
  - 接触阴影：`产品底部有柔和自然的接触阴影，阴影方向统一，不悬浮空中`
- **尺寸与比例**：2K 起步（1K 下材质纹理糊、文字边缘脏）
  - 方图 `1:1`（`--square`）：main product shots for any e-commerce platform, food-delivery images, social posts
  - `3:4` 竖版：Instagram/小红书/TikTok social posts, lookbook pages
  - `16:9`（`--wide`，别名 `--wechat-header`，= 1792×1024，Pro 专属）：banners, website hero, video/social cover, storefront

> **硬约束：** 不出现水印、平台 logo/角标、乱码文字、UI 元素、二维码；不把产品渲染成"开盒/拆封状态"除非 brief 指定；玻璃/液体类严格避免"凭空漂浮的液滴"；瓶身/包装/曲面一律加"无品牌文字、无标签、无 logo"防御；白底图显式写 `纯白背景 #FFFFFF、背景色值准确统一、无暗角、无渐变`，防止模型渲成浅灰底。

## Inspiration Defaults（当 brief 未指定风格时使用）

| 品类 | 默认方向 |
|---|---|
| 白底主图（通用） | 纯白背景、柔和影棚柔光（左右双灯 + 顶部补光）、产品居中 45° 或正前方、底部柔和接触阴影、无杂物 |
| 美食摄影 | 自然窗光（侧光）、木质/大理石/亚麻桌面、45° 或 top-down、暖色调（色温 5000–5500K）、点缀香草/餐具/餐巾、轻微蒸汽/油光增加食欲 |
| 3C 数码 | 深色渐变背景（深灰→黑 或 深蓝→黑）、轮廓背光勾勒边缘、金属/玻璃反光真实、冷色调、少量科技道具（数据线、耳机盒、笔记本一角） |
| 美妆护肤 | 粉色/米色/奶白柔和背景、丝绸/大理石/花/水/水珠点缀、柔光（环形灯/柔光箱）、微距展现膏体/粉饼/瓶身质感 |
| 服饰 lookbook | 模特全身/半身自然姿势 或 flat-lay 平铺、干净浅灰/米白背景或街景 lifestyle、展现面料垂坠感和版型 |
| 食品/茶饮/中式 | 木质茶盘/竹席/陶瓷、逆光水汽/茶香烟雾、中式禅意构图留白、暖木色调 |
| 大促 banner | 红金/蓝金/黑金渐变、礼盒/金箔粒子/光带/礼花点缀、产品居右或居左、另一侧留大字标题空间、2K 16:9 |

> **覆盖规则：** 如果用户 brief 指定了品牌 VI 色、特定场景（户外/办公室/卧室）、特定模特、或特定道具，就放弃灵感默认，只保留结构 guardrails（主角地位、光线约定、文字规则、AI 瑕疵规避）。

## Recipes

所有 recipe 默认使用 Pro 模型、2K 输出。`--square` / `--wide` 等 shortcut（`--wechat-header` 是 `--wide` 别名） 尺寸见具体 recipe。批量迭代同一产品建议首次生成后拿到满意 seed，后续 `--seed` 固定产品本体、只改环境变量以提升一致性。

### Recipe 1：白底电商主图 — 陶瓷马克杯（45° 视角）

最经典的通用白底电商主图模板。纯白底 + 影棚柔光 + 底部投影，产品居中占画面 70%。适用于绝大多数日用品、餐具、小家电、文具等品类，把"米白色哑光陶瓷马克杯"替换成你的 SKU 即可套用。

```bash
uv run scripts/seedream_image_gen.py generate \
  --square \
  --prompt "电商白底主图摄影，一只米白色哑光陶瓷马克杯放在纯白背景 #FFFFFF 上，45° 俯视角度，杯身朝向镜头，杯把手在右侧清晰可见，柔和影棚柔光（左右双灯 + 顶部补光），产品底部有柔和自然的接触阴影，无杂物、无反光板穿帮、无水印、无平台 logo，产品几何形状准确无扭曲，材质为哑光陶瓷质感真实，产品占画面约 70%、居中构图，商业广告摄影质感，高清晰度，适合电商平台主图，1:1 方图"
```

- 推荐尺寸：`--square`（1024×1024，走量快、成本低，SKU 铺量首选）或 `--size 2K`（细节更锐，建议用于主图首图）。
- 套用其他产品：替换"米白色哑光陶瓷马克杯"为具体 SKU 描述，**材质词**一定要写（哑光/亮面/金属/玻璃/磨砂/木纹/皮革）。
- 若渲出灰底：在 prompt 末尾追加强化词 `纯白背景 #FFFFFF、背景色值准确统一、无暗角、无渐变`，出图后用 PS 色阶对白底复核。

### Recipe 2：美食 top-down — 日式寿司拼盘（深色木桌）

深色木质桌面 + 自然光 + top-down 平铺，适用于日料、轻食、早餐、甜品、下午茶、沙拉等摆盘类美食图。是 food social posts / delivery app images 的通用模板。

```bash
uv run scripts/seedream_image_gen.py generate \
  --square \
  --prompt "美食摄影 top-down 俯拍，日式寿司拼盘摆放在深色胡桃木桌面上，拼盘里整齐摆放三文鱼寿司、金枪鱼寿司、虾寿司、加州卷，旁边有一小碟山葵、一小碟酱油、一双黑色筷子斜放、几片腌姜点缀，自然窗光从画面左上方洒入形成柔和阴影，暖色调色温 5000K，食物造型真实自然（不像塑料模型），鱼片有新鲜光泽、米饭颗粒分明、紫菜边缘不发灰，构图留白适当，美食杂志封面质感，高清晰度，无水印无文字，1:1 方图"
```

- 推荐尺寸：`--square`（social posts / 外卖菜品图）或 `--size "1024x1792"`（3:4 竖图 social post cover）。
- 关键负面词：`食物造型真实自然（不像塑料模型）`——Seedream 偶发会把寿司/甜点渲染成塑料质感，这句一定要加。
- 热菜变体（拉面/火锅/小笼包/煲仔饭）：加 `一屡屡自然白色蒸汽从食物上升腾、蒸汽形态柔和真实不过浓`。

### Recipe 3：3C 场景图 — 无线耳机（lifestyle 通勤场景）

深色大理石桌面 + 窗边侧光 + 通勤 lifestyle 道具（包/笔记本/咖啡），产品仍是主角但有场景氛围。适用于耳机、手机、键盘、充电宝、智能手表、相机等 3C 品类的 social product posts / product-detail pages。

```bash
uv run scripts/seedream_image_gen.py generate \
  --size 2K \
  --prompt "3C 数码产品 lifestyle 场景摄影，一副哑光黑色真无线蓝牙耳机（充电盒打开、耳机立在盒中）放在深色大理石纹理桌面上，45° 俯视角度，产品占画面 60%、居中偏左；背景虚化可见：一只卡其色帆布通勤包的一角、一本合上的灰色笔记本电脑的边缘、一杯外带拿铁咖啡（带牛皮纸杯套），窗边透入的柔和自然侧光在耳机金属边缘形成轮廓高光，冷色调蓝灰色，金属和塑料材质反光真实合理、反射合理无穿帮倒影，产品几何形状准确无扭曲，无多余手指穿帮，现代都市通勤氛围，商业广告摄影质感，画面锐利，2K，3:4 竖版"
```

- 推荐尺寸：`--size 2K`（详情页场景图）或 `--size "1024x1792"`（3:4 social product 竖图）。
- 关键：道具只露"一角"——完整的电脑/包会抢戏；写 `背景虚化` 控制景深。
- 金属件必加：`金属反光真实合理、反射合理无穿帮倒影`。

### Recipe 4：美妆场景图 — 口红（丝绸 + 玫瑰花瓣 + 水珠微距）

粉色丝绸 + 玫瑰花瓣 + 水珠 + 柔光微距。适用于口红、粉底、香水、护肤精华、腮红、眼影等美妆品类。是 social beauty posts、品牌详情页的高频模板。

```bash
uv run scripts/seedream_image_gen.py generate \
  --size 2K \
  --prompt "美妆产品微距摄影，一支正红色哑光口红（膏体旋出约 1cm）斜放在粉色褶皱丝绸布料上，45° 俯视角度，丝织品在产品周围形成自然柔软的褶皱；口红周围散落几片深红色玫瑰花瓣，花瓣和膏体上点缀几颗晶莹水珠（水珠形态自然、不凭空漂浮、不悬浮），柔和环形灯柔光、无硬阴影，膏体哑光质感真实细腻、管口金属部分有细腻高光，粉色米色暖色调，产品几何形状准确无扭曲，浪漫精致氛围，美妆广告摄影质感，画面锐利，2K，1:1 方图"
```

- 推荐尺寸：`--size 2K`（微距细节必备 2K，1K 下膏体纹理糊）。
- 水珠必加：`水珠形态自然、不凭空漂浮、不悬浮`——否则容易生成悬浮水滴漂浮在空中。
- 瓶身类（香水/精华）变体：替换主体为产品，加 `玻璃折射真实合理，但不追求复杂内部反射，瓶身标签文字清晰可读（如有）`。

### Recipe 5：服饰 flat-lay — 白 T + 牛仔裤 + 帆布鞋（米色亚麻布）

米色亚麻布 + 45° top-down 平铺 + 配件点缀（墨镜/杂志/咖啡）。适用于服饰、配饰、鞋包的 fashion social posts / store new-arrivals。

```bash
uv run scripts/seedream_image_gen.py generate \
  --size 2K \
  --prompt "服饰 flat-lay 平铺摄影 top-down 俯拍，米色亚麻布料铺底（布料有自然褶皱、不僵硬平整），画面中央平铺一件纯白色基础款棉质 T 恤（棉质面料纹理可见、自然铺开不僵硬、无塑料光泽），T 恤下方压着一条浅蓝色直筒牛仔裤（裤脚微微卷起、牛仔布纹理清晰），右下角一双米白色高帮帆布鞋（鞋头朝左下、帆布和橡胶材质分明），配饰点缀：右上角一副黑色墨镜、T 恤右侧一本卷起的时尚杂志、左下角一杯外带冰美式咖啡（透明杯身可见冰块），自然窗光从左上洒下形成柔和投影，整体米白蓝冷调 + 一点咖啡暖色点缀，干净整洁的穿搭布局，无多余杂物，电商服饰摄影质感，2K，3:4 竖版"
```

- 推荐尺寸：`--size "1024x1792"`（3:4 fashion social 竖图）或 `--size 2K`。
- 真人模特 lookbook 变体：把 flat-lay 描述改成 `一位 20-30 岁东亚女性模特身着白 T + 浅蓝色直筒牛仔裤自然站立，米白摄影棚无缝背景，柔和影棚光，模特自信看向镜头，展现棉质面料垂坠感和牛仔裤版型，手部自然下垂、手指自然无多指畸形无手指融合，lookbook 商业摄影质感，3:4 竖版`。手模场景**必须**加 `手指自然无多指畸形无手指融合`，并批量出 4–8 张挑选。
- 面料质感要写具体：`棉质` / `真丝` / `羊毛针织` / `牛仔布` / `皮革` / `亚麻`，统一写"衣服"会出化纤反光感。加 `面料纹理可见、垂坠感自然、无塑料光泽` 更稳。

### Recipe 6：美食 45° — 小笼包（竹蒸笼 + 蒸汽 + 暖黄灯光）

竹蒸笼 + 白烟蒸汽 + 暖黄餐灯光 + 香醋姜丝小碟。适用于中式点心、汤面、火锅、烧烤、煲仔饭、烧腊等热菜场景，是 food delivery apps、local food social accounts、restaurant marketing 的主力图模板。

```bash
uv run scripts/seedream_image_gen.py generate \
  --size 2K \
  --prompt "中式美食摄影 45° 俯视，一笼竹制蒸笼摆在深棕色实木餐桌上，蒸笼里整齐摆放 8 只小笼包（包子皮薄而半透明、顶部 18 道褶皱清晰可见、隐约可见内部汤汁），蒸笼盖半开冒着缕缕自然白色蒸汽（蒸汽形态柔和真实、不过浓不遮挡主体），蒸笼右侧放一小碟深色香醋、碟子里有几缕姜丝、一双竹筷横放在碟边，桌面散落几片竹叶点缀，暖黄餐灯光从左上方打来形成暖色调氛围，食物造型真实自然不像塑料模型，包子皮有柔软光泽、木桌有自然木纹纹理，中式点心食欲感强，美食杂志封面质感，画面锐利，色彩真实自然、不过饱和、白平衡准确，2K，3:4 竖版"
```

- 推荐尺寸：`--size "1024x1792"`（3:4 local food social 竖图）或 `--square`（food-delivery app images）。
- 蒸汽关键词：`自然白色蒸汽、形态柔和真实、不过浓不遮挡主体`——太浓会把产品糊成一团白雾。
- 色彩控制：暖黄光 + 红色/橙色食物（红烧肉、麻辣火锅、番茄酱意面）常把红色渲染成荧光橙红。务必加 `色彩真实自然、不过饱和、白平衡准确`；若仍过艳，把"暖黄餐灯光"改成"自然窗光 5000K"重试。

### Recipe 7：中式茶席场景 — 紫砂壶 + 茶杯（禅意逆光）

1. **策略 1（最稳 10/10，G1）：把手藏起来**——揣兜、背在身后、被道具/衣服/构图切掉。"双手插入牛仔裤前口袋，只露出拇指搭在袋口"——G1 拿到 9/10，只有拇指可见、无 6 指畸形。

## Ghost Mannequin / 隐形模特 / 手规避（服装/服饰类必读）

服装和带手产品图是 AI 图像传统翻车重灾区。按实测稳定性排序，推荐三种策略：

### 策略 1：藏手（最稳，10/10）

G1 实测——把双手完全藏起来是唯一零风险方案：
- 双手插牛仔裤/外套口袋，只露拇指搭在袋口（G1：9/10，仅拇指处轻微皮肤-牛仔融合）
- 背手/手在身后构图外（中景/3/4 裁剪到前臂）
- 手臂交叉抱胸，手部被手臂/衣服遮挡
- cropped at elbows / waist-up 构图切掉
- 背影/侧影（不看到手）

推荐 prompt 片段：`双手插入裤子前口袋，拇指搭在袋口自然外露，其余手指藏在袋内不可见，无手指畸形，手部自然`。

### 策略 2：让手"有事做"（6-7/10，保底可用）

G2 实测——双手拿道具（咖啡杯、书、手机、包带、盆栽、太阳镜、外套翻领）比空手好，因为道具遮挡了手指之间的位置。G2 拿咖啡杯 7.5/10（握把手处有轻度融合），G5 拿盆栽 8/10（加了负 prompt 后提升半档）。

必做：
- 加手负 prompt（见 Recipe 10 的 G5 negative）
- 道具遮挡点合理（杯把、书脊、包带），不要让手掌大面积裸露
- 批量出 4-8 张挑最好的一张
- 手部占画面比例越小越安全（中景比特写安全，远景比中景安全）

### 策略 3：Ref-guided 双手（8-9/10，推荐）

G6 实测——分两步：(1) 单独在 1:1 特写里生成一双干净的手+道具，(2) 用 `edit --reference-image` 把这双手的姿势/解剖结构带到全身肖像里。两步总共约 ¥0.60-1.20，但手畸形率从 ~60% 降到 ~10%。

- 第一步用简洁 1:1 特写（无全身干扰，专注手解剖）
- 第二步 prompt 里显式重申"每只手 5 根手指、完美解剖结构、自然指甲"
- 会有 pose drift（握法变化）但不会出现 6 指/融合/断指
- 不保证手指 pose 100% 复刻，但保证可编辑的干净结果

### 三种策略选择决策树

```
需要 POD/白底服装主图，不要真人？   → 策略 ghost mannequin（Recipe 9）/ flat-lay（Recipe 5）
需要真人 lookbook，构图允许藏手？  → 策略 1（揣兜/背手/裁剪）
需要真人 lookbook，手必须拿道具？  → 策略 3（ref-guided，Recipe 10）；时间紧才用策略 2（直接拿道具+负 prompt）
需要真人 lookbook，手必须裸露？    → 策略 3（ref-guided）且批量出 8 张挑；或用手模实拍合成
```

### 手专用 Negative Prompt（中文版，叠加在默认 negative 上）

```
手部畸形, 多余手指, 手指融合, 手指缺失, 六指, 断指, 指甲畸形,
手和道具融合穿帮, 手指数量错误, 手看起来塑料不真实
```

（英文版见 Recipe 10；服装/人物场景中英混合最稳。）

## 翻车提醒（高频踩坑）

1. **透明玻璃杯 / 复杂折射液体是硬骨头。** 简单的一杯水、一瓶透明精华液可以出图，但多层玻璃（叠杯、酒杯碰杯、水晶灯折射）、复杂液体漩涡、香槟气泡柱、多层冰块折射 Pro 仍会出现折射穿帮。这类场景建议用实拍 + 后期合成，AI 仅作概念草图。
2. **珠宝 / 钻石 / 贵金属刻面不真实。** 钻石火彩、宝石刻面反射、黄金镜面效果 AI 出图常发灰或发糊，无法替代专业珠宝摄影。建议 AI 只做场景氛围 + 款式概念图，最终销售图用实拍。
3. **美食暖光下容易过饱和。** 暖黄光 + 红色食物（红烧肉、麻辣火锅、番茄酱意面、红油抄手）常把红色渲染成荧光橙红，看着不像食物。出图后若色彩溢出，在 prompt 末尾加 `色彩真实自然、不过饱和、白平衡准确`，或把"暖黄餐灯光"改成"自然窗光 5000K"，批量重跑。
4. **手模必加"手指自然、无多指畸形"。** 服饰/美妆/3C 带手模特的图，即使用了负面词，Seedream 仍偶发 6 指/手指融合/指甲畸形。建议批量出 4–8 张选最好的一张；手部占画面比例越小越安全。
5. **反射面不要放写实名牌/人脸。** 镜子、手机屏幕、眼镜镜片、金属刀叉里的反射内容模型会自由发挥。如果品牌方对反射内容敏感（不能出现竞品 logo、不能出现人脸），prompt 里加 `反射面内容为模糊虚化的环境光、无具体文字、无清晰人脸或品牌倒影`。
6. **商品标签文字控制 ≤8 字符。** 价格牌（如"¥99"、"特价"、"NEW"、"HOT"）成功率高；长段产品卖点、功效说明、成分表、多行使用说明不要让模型生成——后期用 PS/Figma 叠加更稳。
7. **白底主图注意"隐性灰底"。** 模型偶发会把纯白背景渲染成浅灰或带色偏。显式写 `纯白背景 #FFFFFF、背景色值准确统一、无暗角、无渐变`，出图后用 PS 色阶对白底复核，必要时魔棒一键换纯白。
8. **服饰面料质感要写具体。** 不要统一写"衣服"——要写"棉质 T 恤"、"真丝连衣裙"、"羊毛针织开衫"、"牛仔外套"、"皮革手袋"。加 `面料纹理可见、垂坠感自然、无塑料光泽` 更稳。
9. **批量迭代同一产品固定 seed。** 跑主图 A/B 测试（换背景/换光线/换角度/换配色）时，先用一次生成拿到满意的 seed 值（返回 JSON 里有 `seed` 字段），后续通过 `--seed` 固定产品本体、只改环境变量，可大幅提升产品造型一致性，节省选图时间。
10. **人物皮肤/肤质偶发塑料感。** 美妆/服饰带模特的图，如果皮肤渲染过于光滑像塑料，加 `皮肤质感真实、毛孔自然、不过度磨皮`。东亚模特建议显式写 `东亚女性/男性模特`，避免被渲染成其他人种。
11. **食物上的"假字"要排查。** 外卖/零食包装、瓶身标签上模型偶发会乱填中文或英文（看似品牌名实则乱码）。带包装的产品图务必人工检查标签文字；如果不需要包装文字，加 `瓶身/包装盒无文字、纯白无标签版本` 或 `品牌标签区域留白后期叠加`。
12. **镜面/屏幕反射里的"鬼影"。** 手机屏幕、笔记本屏幕、墨镜镜片上模型常渲染出不存在的窗口、文字或人脸。需要"黑屏"或"花屏"效果时显式写 `屏幕纯黑无显示无反射内容`；需要显示内容时逐字写出屏幕上显示什么（如 `屏幕显示锁屏壁纸、无应用图标`）。
13. **电商大促红色容易翻车成"廉价红"。** 大促 banner 如果要高级感，把"大红色"换成 `酒红 #8B0000` / `深红渐变` / `哑光红`，再加金色描边或金箔粒子提升质感；纯大红色 + 粗黑字容易渲出县城促销感。
14. **同一产品不同图的色差问题。** SKU 铺图（同一款杯子出 5 个颜色主图）时，先固定 seed，再只改颜色词，并用色值描述（`莫兰迪粉 #E8C5C0`、`雾霾蓝 #8DA3B5`）比用模糊形容词（"浅粉色"、"蓝色"）颜色稳定性更高。

当你需要快速出一张产品图、又不想完整抄写 recipe 时，可以用以下"骨架 prompt"填空：

```
[品类] 产品摄影，[具体产品名 + 材质 + 颜色]，[背景描述]，[光线 setup]，[视角] 角度，产品占画面约 [60-70]%、[构图位置]，[点缀道具，不超过 3 样，每样只露一角]，[色调]，产品几何形状准确无扭曲、材质质感真实、反射合理无穿帮、无水印无乱码文字无平台 logo，商业广告摄影质感，高清晰度，[比例]
```

填空示例（一盒抹茶饼干）：
```
美食产品摄影，一盒墨绿色铁盒装抹茶曲奇饼干（铁盒盖子半开、露出几块饼干），浅米色亚麻餐布背景，自然窗光从左上洒入，45° 俯视角度，产品占画面约 65%、居中偏左，旁边点缀一小碟抹茶粉、一杯清茶（只露杯沿）、几片散落茶叶，绿色米色暖色调，食物造型真实自然不像塑料模型、铁盒印刷质感真实、无扭曲变形、无水印无文字，美食广告摄影质感，高清晰度，3:4 竖版
```

骨架 prompt 适合 80% 的常规产品图场景；对质感要求高（微距珠宝/玻璃香水/金属 3C）建议还是从对应 recipe 完整抄写，保证负面词加到位。
