# 编辑式铅笔淡彩手绘风格

一种温暖的手绘插画风格：在白纸或米白纸上用铅笔/钢笔线稿打底，局部晕染低饱和淡彩，像设计师速写本里的概念草图。理性但不冷淡，结构清晰但带有人工痕迹。适合表现 AI 工作流、创作流程、编辑式解释图、人机协作场景。

## 风格签名

| 维度 | Prompt 关键词 |
|---|---|
| 媒介 | `手绘铅笔线稿`, `钢笔线描`, `淡彩晕染`, `速写本风格`, `白纸上的插画` |
| 色彩 | `低饱和淡彩`, `浅蓝`, `薄荷绿`, `陶土橙`, `淡紫`, `石墨灰色线稿` |
| 背景 | `纯白背景`, `大量留白`, `无暗角` |
| 构图 | `等距故事板布局`, `从左到右流程图`, `分镜面板`, `缩略图网格`, `概念图` |
| 主体 | `人类与友好的机器人协作`, `设计师伏案工作`, `圆润可爱的机器人助手`, `创意工作空间` |
| 道具 | `放大镜`, `剪刀`, `便利贴`, `时间轴`, `分镜面板`, `情绪板`, `场记板` |
| 氛围 | `温暖的编辑式插画`, `理性而舒适`, `创客空间氛围`, `创作过程可视化` |
| 避免 | `写实照片`, `深色背景`, `霓虹色`, `厚重阴影`, `3D 渲染感`, `扁平矢量插画` |

```text
一张温暖的编辑式插画，手绘铅笔线稿叠加淡彩晕染，纯白背景。

场景：[发生什么——例如 AI 与人类协作的写作工作流、视频剪辑流水线、研究过程]。
构图：[场景如何布局——例如等距故事板、从左到右的流程、中央工作台 surrounded by 缩略图]。
细节：[关键道具和角色——例如作家、圆润可爱的机器人、便利贴、时间轴、分镜面板、放大镜]。
色彩：低饱和淡彩点缀——浅蓝、薄荷绿、陶土橙、淡紫；线稿保持石墨灰色。
氛围：理性而温暖，人机协作，留白充足，不杂乱。
避免：写实照片感、深色背景、霓虹色、厚重阴影、3D 渲染感。
```

## 变体

- **偏冷/更技术感**：把 `薄荷绿、陶土橙` 换成 `石板蓝、淡青色、银灰`，让线稿占主导。
- **偏暖/更个人化**：加入 `暖米色纸张`、`深褐墨水`、`蜂蜜色高光`。
- **更偏图表/ less 场景**：强调 `概念图`、`带标签的节点`、`虚线箭头`、`小图标`。
- **更简洁/主视觉**：减少道具到一个人物 + 一个大型对象，保持 60% 以上留白。

## 技巧

1. 先把媒介锚定（`手绘铅笔线稿叠加淡彩晕染`），再描述场景，模型更容易锁定风格。
2. 明确写 `纯白背景`、`无暗角`；否则 Seedream 容易默认给素描配灰色纹理背景。
3. 图中有小标签、图标或密集流程细节时，使用 `2K` 或 `4K` 尺寸。
4. 如果图中需要出现文字，用中文引号 "" 包裹具体文字，并参考 [text-effects.md](text-effects.md) 的中文文本渲染技巧。
