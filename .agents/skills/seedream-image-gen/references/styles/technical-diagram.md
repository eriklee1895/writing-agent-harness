# 技术架构/图表风格

适合：技术文章、系统设计文档、产品架构说明、SaaS 介绍、工作流/方法论文章。

## 风格清单

### 1. 扁平等距插图

灵感：等距视角、分层模块、清晰的视觉层级。适合系统架构图、产品演示、SaaS 说明。

**核心公式**:
```
扁平等距插图风格，[系统/产品名]架构示意图，[层数]层结构，不同颜色区分模块，箭头标注数据流向，现代科技感配色，白底
```

**示例**:
```
扁平等距插图风格，微服务架构示意图，4层结构（前端层→API网关→服务层→数据层），蓝紫渐变配色，箭头标注请求流向，标注清晰，信息图风格，白底
```

```
等距3D插图，SaaS产品功能模块展示，中央平台连接用户端、管理端、数据分析端，柔和蓝白配色，模块化卡片布局，无文字，信息图感
```

**适用场景**: 系统架构、产品总览、模块关系图

---

### 2. 信息图/Process Flow

灵感：步骤时间线、流程图、双语标签。Seedream 5.0 在信息图生成上表现突出，尤其文字渲染能力强。

**核心公式**:
```
生成一张高质量的信息图，解释[主题/流程]，[步骤数]个步骤，每步配简洁文字说明和插图，[配色/风格]，2K分辨率
```

**示例**:
```
生成一张高质量的信息图，解释啤酒酿造过程，5个步骤（糖化→煮沸→发酵→陈酿→装瓶），每步配简洁中文说明和插画，温暖棕色调，信息图风格，2K
```

```
流程图风格，从需求分析到上线的完整软件开发流程，时间线从左到右展开，6个关键节点标注，每个阶段配图标，蓝紫色科技感配色，白色背景，2K
```

**适用场景**: 工作流教程、方法论介绍、步骤指南、时间线

---

### 3. 科学图表/教科书风

灵感：白底、标注清晰、学术感排版。适合知识密度高的科普、教材插图。

**核心公式**:
```
科学示意图风格，[概念/过程名称]，[视觉描述]，标注清晰，排版干净，适合教材插图，白色背景
```

**示例**:
```
科学示意图风格，光合作用过程，展示光反应和暗反应路径，彩色插画风格，标注ATP和NADPH的生成与消耗，排版清晰，适合教材插图，白色背景，2K
```

```
解剖示意图风格，人脑功能区划分，左右半球对比展示，不同颜色标注前额叶、运动皮层、语言区等，医学插画风格，标注清晰中英文，白色背景
```

**适用场景**: 科普文章、教材插图、知识卡片、学术笔记

---

### 4. 蓝图/线框风

灵感：蓝图设计感、线框、正交视图。适合系统设计文档、API 文档、开发者博客。

**核心公式**:
```
蓝图风格，[系统/工具]技术示意图，线框布局，青色线条白色背景，[尺寸]比例，干净清晰的工程感
```

**示例**:
```
蓝图风格，Kubernetes集群架构示意图，线框布局展示Master节点和Worker节点间的关系，青色线条白底，清晰的工程感，标注清晰，16:9
```

**适用场景**: 开发者文档、CI/CD 图示、API 设计图

---

## 通用技术图技巧

1. **文字渲染**: Seedream 5.0 文字渲染能力强。用双引号包裹画面中的具体文字。
2. **配色**: 蓝紫/深蓝/青绿 科技感强；橙黄/温暖色调 适合教程；白底最干净。
3. **标注**: 箭头、连接线、分组方框明确标注"用箭头连接"、"用虚线分组"。
4. **简化**: 技术图不要塞太多信息。每张图 3-6 个核心模块最佳。
5. **比例**: 技术图推荐横向 `16:9` 或 `2K`，适配 PC 阅读。
