# 技术架构/图表风格

适合：技术文章、系统设计文档、产品架构说明、SaaS 介绍、工作流/方法论文章。

本 preset 提供的是**脚手架而非模具**：它默认使用白底、模块化卡片/流程布局和科技感配色，但当用户 brief 已经带有强烈视觉概念时，模型应只保留结构 guardrails，让出风格自由。

我们把技术图分成两个层级，避免把“简洁总览”和“详细架构图”混用：

- **简洁总览：** [`技术图表-简洁`](#1-技术图表-简洁) — 产品演示、模块关系、SaaS 概览。
- **详细架构：** [`技术图表-架构`](#2-技术图表-架构) — 带编号步骤、组件标签、数据流、图例的完整架构图。

## 结构模板（除非 brief 覆盖，否则保留）

| Guardrail | 默认 Prompt 关键词 |
|---|---|
| 媒介 | `简洁扁平技术示意图`, `轻3D信息图`, `现代信息设计`, `技术架构图` |
| 背景 | `白底`, `干净无纹理`, `无暗角` |
| 构图 | `模块化卡片布局`, `层级分明`, `箭头标注流向`, `编号步骤`, `组件标签`, `底部图例` |
| 硬约束 | `避免写实照片感`, `避免厚重3D渲染`, `避免深色背景`, `避免装饰性冗余`, `长段正文文字后期处理而非生成` |

## 灵感默认（当 brief 自带风格/氛围/配色时可被覆盖）

| 子风格 | 默认方向 |
|---|---|
| 简洁总览 | `现代科技感配色`, `蓝紫渐变`, `柔和蓝白`, `模块化色块` |
| 详细架构 | `蓝紫/青绿配色`, `扁平或轻3D`, `标注清晰`, `信息图风格` |
| 信息图/流程图 | `蓝紫/深蓝/青绿`（科技感）或 `橙黄/温暖色调`（教程感） |
| 科学图表 | `学术感配色`, `白底`, `清晰标注` |
| 蓝图/线框 | `青色线条白底`, `工程感`, `线框布局` |

> **覆盖规则：** 如果用户指定了不同的配色、渲染风格或布局，就放弃灵感默认，只保留结构模板（白底、模块/流程构图、硬约束）。

## 1. 技术图表 — 简洁

高层次的简洁总览。适合做头图、缩略图、产品页说明，不需要密集标签。

**核心公式**:
```
简洁扁平/轻3D技术示意图，[系统/产品名]总览，[N]个模块，色块区分，箭头标注流向，现代科技感配色，白底；模块标签用2-4字英文/中文短词，逐字写出，小字号无衬线字体
```

**示例（完整 preset）**:
```
简洁扁平技术示意图，微服务架构总览，4层模块（前端层→API网关→服务层→数据层），蓝紫渐变配色，箭头标注请求流向，模块化卡片布局，白底；每个模块方块内带小字号黑色无衬线标签"前端"、"API网关"、"服务"、"数据"
```

```
轻3D信息图风格，SaaS产品功能模块展示，中央平台连接用户端、管理端、数据分析端，柔和蓝白配色，模块化卡片布局，小字号英文无衬线标签"User"、"Admin"、"Analytics"、"Platform"，信息图感，白底，2K
```

**适用场景**: 产品总览、模块关系图、落地页头图

---

## 2. 技术图表 — 架构

需要讲清楚“怎么工作”的架构图。带编号步骤、组件标签、数据流注解和图例。

**核心公式**:
```
详细技术架构图，[系统/主题]，[N]个编号步骤或层级，每个组件方块带短标签（逐字写出，2-4字/词，小字号monospace或无衬线字体），箭头标注数据流向，底部图例说明，现代扁平或轻3D风格，白底，2K
```

**示例（完整 preset）**:
```
详细技术架构图，解释RAG检索增强生成原理，5个编号步骤从左到右：1"Query"、2"Retrieve"、3"Prompt"、4"LLM"、5"Answer"。每个步骤用一个带小字号黑色无衬线标签的组件方块和图标表示，箭头连接各步骤，底部一行图例说明各组件。现代扁平风格，蓝紫配色，白底，标注清晰，2K
```

**适用场景**: 架构深度解析、方法论讲解、开发文档、工作流教程

---

## 3. 信息图 / 流程图

步骤时间线、流程图、双语标签。Seedream 5.0 在信息图生成上表现突出，尤其文字渲染能力强。

**核心公式**:
```
生成一张高质量的信息图，解释[主题/流程]，[步骤数]个步骤，每步配简洁文字说明和插图，[配色/风格]，2K分辨率
```

**示例（完整 preset）**:
```
生成一张高质量的信息图，解释啤酒酿造过程，5个步骤（糖化→煮沸→发酵→陈酿→装瓶），每步配简洁中文说明和插画，温暖棕色调，信息图风格，2K
```

```
流程图风格，从需求分析到上线的完整软件开发流程，时间线从左到右展开，6个关键节点标注，每个阶段配图标，蓝紫色科技感配色，白色背景，2K
```

**适用场景**: 工作流教程、方法论介绍、步骤指南、时间线

---

## 4. 科学图表 / 教科书风

白底、标注清晰、学术感排版。适合知识密度高的科普、教材插图。

**核心公式**:
```
科学示意图风格，[概念/过程名称]，[视觉描述]，标注清晰，排版干净，适合教材插图，白色背景
```

**示例（完整 preset）**:
```
科学示意图风格，光合作用过程，展示光反应和暗反应路径，彩色插画风格，标注ATP和NADPH的生成与消耗，排版清晰，适合教材插图，白色背景，2K
```

```
解剖示意图风格，人脑功能区划分，左右半球对比展示，不同颜色标注前额叶、运动皮层、语言区等，医学插画风格，标注清晰中英文，白色背景
```

**适用场景**: 科普文章、教材插图、知识卡片、学术笔记

---

## 5. 蓝图 / 线框风

蓝图设计感、线框、正交视图。适合系统设计文档、API 文档、开发者博客。

**核心公式**:
```
蓝图风格，[系统/工具]技术示意图，线框布局，青色线条白色背景，[尺寸]比例，干净清晰的工程感
```

**示例（完整 preset）**:
```
蓝图风格，Kubernetes集群架构示意图，线框布局展示Master节点和Worker节点间的关系，青色线条白底，清晰的工程感，标注清晰，16:9
```

**适用场景**: 开发者文档、CI/CD 图示、API 设计图

## 通用技术图技巧

1. **按层级选模板。** 总览用"简洁"，需要讲流程用"架构"。
2. **文字渲染（Seedream 5.0 Pro）**: 方块标签、箭头 callout 在 2K 下可稳定渲染；每个标签控制在 ≤4 个字/词，逐字写进 prompt 并用引号包裹，指定小字号 monospace 或无衬线字体；多行段落、长说明文字、数学公式仍需后期叠加。参考 [text-effects.md](text-effects.md)。
3. **配色**: 蓝紫/深蓝/青绿 科技感强；橙黄/温暖色调 适合教程；白底最干净。
4. **标注**: 箭头、连接线、分组方框明确标注"用箭头连接"、"用虚线分组"。
5. **架构图必须显式要求**: 编号步骤、组件标签、数据流箭头、底部图例。否则模型容易压成几个通用图标。
6. **尺寸**: 需要清晰可读的标签/箭头文字时优先 `2K`；纯总览缩略图可用 `16:9`。
7. **不要硬追求等距 3D**: Seedream 对“扁平等距”理解不稳定，扁平或轻 3D 信息图更可控。
8. **当用户 brief 已自带配色或渲染风格时，放弃灵感默认，只保留结构 guardrails。**
