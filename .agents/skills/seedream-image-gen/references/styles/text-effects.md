# 文字特效 / 字体风格（Pro 版）

> 本 preset 在 Seedream 5.0 Pro 上效果最好——Pro 的中文/英文文字渲染是 headline 能力，比 Lite 明显更强。Lite 仍可用但要注意小字错字、字间距不匀。

文字特效通用公式：
```
"[文字内容逐字写准，引号包起]" + [字体族/字重] + [字效风格描述] +
[背景/版式/装饰] + [对齐/位置/字号比例] + [整体风格/尺寸]
```

### 文字渲染注意事项（Pro）

1. **2K 起步**——1K 下文字边缘会糊，Pro 的额外延迟几乎没有但文字质量显著提升。
2. **短文字优于长文字**——主标题 2–12 字最佳，超过 15 字建议分行；大段正文（8 行以上）还是要人工后期。
3. **用引号包裹逐字内容**——确保模型知道哪些是文字，不要写"一个关于 XX 的标题"。
4. **中英混排分行写**——中文一行、英文一行，并说"中英字体字号视觉平衡"。
5. **生僻字/品牌名拼写提示**——罕见字可以加注"大写的 X"或拆字说明。
6. **环形/弧形字明确说"沿圆环顶部/底部弧形排列"**——这个 phrase 模型识别很准。
7. **小字标签 ≤4 字**——信息图/卡片标签越短越稳；数字（年份/百分比）也很稳。
8. **不要指望像素级排版**——AI 出图的字距/位置是 approximate，需要精确到 1px 的请后期用 Canvas/Figma 加字。

### 仍然会翻车的场景

- 连笔草书/医生处方/手写长文——笔画结构不闭合
- 密集表格/乐谱/数学公式/棋谱——结构性符号系统
- 极小字号（< 画面高度 1/30）的段落文字——错字累积
- 需要精确排版（如报纸头版多行对齐）——模型不做网格系统
