# 教育/科普风格

适合：教育文章、科普专栏、知识卡片、how-to 教程、学术讲解、学习笔记。

本 preset 提供的是**脚手架而非模具**：它默认使用步骤化/标注化的教育布局和干净的学术配色，但当用户 brief 已经带有强烈视觉概念时，模型应只保留结构 guardrails，让出风格自由。

## 结构模板（除非 brief 覆盖，否则保留）

| Guardrail | 默认 Prompt 关键词 |
|---|---|
| 媒介 | `手账/教程图`, `结构示意图`, `教科书插图`, `知识卡片`, `绘本风格` |
| 背景 | `白色背景`, `干净布局`, `少装饰` |
| 构图 | `步骤整合长图`, `标注清晰`, `图标+简短文字`, `层次/金字塔/环形结构`, `3-6 个核心信息点` |
| 硬约束 | `避免写实照片感除非用户要求`, `避免深色背景`, `避免超过 8 个信息点`, `长段正文/多行说明后期处理而非生成` |

## 灵感默认（当 brief 自带风格/氛围/配色时可被覆盖）

| 子风格 | 默认方向 |
|---|---|
| 手账/教程 | `温馨厨房色调`, `手账风格`, `绿色健身主题`, `可爱图标` |
| 结构示意图 | `温暖渐变色`, `绿色生态配色`, `教育插图风格` |
| 教科书/学术 | `学术配色`, `浅蓝底色`, `清晰标注` |
| 知识卡片 | `深蓝底白字`, `柔和蓝白配色`, `竖版 9:16` |
| 儿童/绘本 | `宫崎骏风格`, `色彩明快温暖`, `绘本插图感`, `亲和角色` |

> **覆盖规则：** 如果用户指定了不同的画风、配色或布局，就放弃灵感默认，只保留结构模板（白底、步骤/标注化构图、硬约束）。

## 1. 手账/教程步骤图

手账/笔记风格、步骤整合长图、中文标注。适合 how-to 教程、食谱、手工指南。

**核心公式**:
```
手账风格/教程图风格，制作一份[主题]的步骤教程，所有步骤整合在一张图中，步骤说明使用中文，[补充细节]
```

**示例（完整 preset）**:
```
手账风格，制作一份西红柿炒鸡蛋的步骤教程图，所有步骤整合在一张长图中，4个步骤（备菜→炒蛋→炒番茄→合炒装盘），每步配插图和中文字说明，温馨厨房色调
```

```
教程卡片风格，如何正确做深蹲的步骤图解，5个步骤整合长图，人体侧视图展示每个阶段的姿势，绿色健身主题配色，标注中文要点
```

**适用场景**: 食谱、运动教程、DIY 指南、生活技巧

**适用场景**: 学术概念解释、理论框架、关系图

## 教育科普图通用技巧

1. **信息密度适中**: 一张图 3-6 个核心概念最佳，不要塞入超过 8 个信息点。
2. **短标签可直出（Seedream 5.0 Pro）**: 2K 下图解上的短标签（如"轴突/axon"、"细胞核/nucleus"、步骤序号旁的 2-4 字中文）可稳定渲染——逐字写进 prompt 并用引号包裹，指定小字号清晰无衬线字体；长段解释、多行定义、数学公式、化学方程式仍建议后期叠加。参考 [text-effects.md](text-effects.md)。
3. **白底优于彩色底**: 教育图白底最干净，彩色底容易分散注意力。
4. **用图标辅助**: 每个概念配一个简洁图标，帮助视觉记忆。
5. **步骤图用序号**: 1→2→3→4 的序号 + 箭头，比纯文字说明更清晰。
6. **9:16 适配手机**: 如果需要微信传播，用 `--size "1024x1792"` 竖版；含标签文字时优先 `2K`。
7. **当用户 brief 已自带画风或配色时，放弃灵感默认，只保留结构 guardrails。**
