# Article Illustration Docs

`article-illustration` 是项目级写作 workflow 的视觉能力，用于生成文章封面、正文插图、章节视觉分隔图和技术图示。

阅读顺序：

- [guide.md](guide.md)：稳定规则、风格选择、prompt pattern 和尺寸约定。
- [cases/](cases/)：历史优质生图案例，记录为什么有效、可复用机制和不要机械复制的部分。

## Boundary

`guide.md` 只放已经稳定的规则；单篇文章的出图过程、审美判断和踩坑经验先放 `cases/` 或 retrospectives。只有反复验证有效的机制，才提升回 guide。

案例不是模板库。Agent 可以学习其中的判断方式、视觉功能和反风格，不要机械复制某次成功 prompt、构图、色调或图片数量。
