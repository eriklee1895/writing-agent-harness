🛠 Skill System 快速参考卡

项目级与全局级 Skills 配置、目录结构、使用速查

1 初始化项目级 Skills

在你的项目中配置 Skills

创建目录

mkdir -p .agents/skills

Claude Code 软链接（如需要）

mkdir -p claude && ln -s ../.agents/skills claude/skills

验证

ls -la .agents/skills/

2 安装全局 Skills

跨项目使用的通用 Skills

标准位置

mkdir -p ~/.agents/skills

从 GitHub 安装

npx skills add username/repo

安装指定 Skill

npx skills add eriklee1895/writing-agent-harness --skill article-ideation

3 创建新 Skill

从零创建一个新 Skill

基本结构

cd .agents/skills mkdir my-new-skill cd my-new-skill touch SKILL.md

可选目录

mkdir -p scripts references agents

✓ Git 配置检查

确保 Skills 正确提交

  • .agents/skills/ 被 Git 跟踪
  • .env 在 .gitignore 中
  • .local-memory/ 在 .gitignore 中
  • Secrets 不提交

验证命令

git check-ignore -v .agents/skills/*/SKILL.md

📁 完整目录结构

your-project/ ├── .agents/ │ └── skills/ 项目级 │ ├── skill-name/ │ │ ├── SKILL.md 必需 │ │ ├── README.md 可选 │ │ ├── agents/ │ │ │ ├── claude/ │ │ │ └── codex/ │ │ ├── scripts/ │ │ ├── references/ │ │ └── tests/ │ ├── ~/.agents/skills/ 全局级 │ ├── tavily-search/ │ └── imagegen/

📝 SKILL.md 模板

Frontmatter（YAML）

--- name: skill-name description: | 中文触发语义。 Use when: user says X, Y, Z. Do not use when: ... metadata: requires: bins: ["node", "uv"] skills: ["other-skill"] env: ["API_KEY"] ---

正文（Markdown）

# Skill Title ## Overview 简要说明。 ## When To Use - 什么时候用 ## When NOT To Use - 什么时候不用 ## Workflow 步骤说明。

🔗 路径变量 {baseDir}

在文档中引用 skill 目录：

在 SKILL.md 中写

node {baseDir}/scripts/render.mjs

运行时替换为

node /path/to/.agents/skills/skill-name/scripts/render.mjs

📦 安装与管理

安装所有 Skills

npx skills add eriklee1895/writing-agent-harness

安装指定 Skill

npx skills add eriklee1895/writing-agent-harness --skill article-ideation

查看已安装 Skills

ls -la ~/.agents/skills/ ls -la .agents/skills/

🐍 Python 脚本

统一使用 uv 运行：

uv run scripts/your-script.py --help

添加依赖

uv add requests

同步环境

uv sync

🟢 Node.js 脚本

node scripts/your-script.mjs

预览微信文章

node .agents/skills/wechat-article-renderer/scripts/render-wechat-article.mjs \ content/origin/YYYY-MM-DD-slug/article.md \ --style agent-flow
