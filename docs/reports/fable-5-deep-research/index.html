隐于神话：Claude Mythos 5

当今最强大的大型语言模型，却不对公众开放。如同古希腊神话中隐于奥林匹斯山巅的众神，Mythos 5 的性能令人敬畏，却鲜有人能亲眼见证。

核心要点 Mythos 5 与 Fable 5 是"同一枚硬币的两面"——前者是去除限制的原生形态，后者是面向大众的安全版本。两者在绝大多数基准测试中的分数差距仅在 1-3 个百分点 之间。如果 Mythos 5 是隐藏在云层之后的神祇，Fable 5 就是它走入人间的化身。
Restricted Access

Claude Mythos 5

模型等级的全新巅峰——Mythos-class 的首个代表。访问权限严格限制在 Project Glasswing 合作伙伴： 网络安全防御团队、关键基础设施运营者、经审核的生物医学研究人员。 在特定领域移除了安全分类器，能够直接访问模型的全部原始能力。

Public Release

Claude Fable 5

2026年6月9日，首个面向公众开放的 Mythos-class 模型。与 Mythos 5 共享完全相同的底层权重和架构， 区别仅在于安全分类器的配置。用智能路由而非生硬拒绝来平衡能力与安全—— 敏感查询自动降级到 Opus 4.8，而非直接返回拒绝信息。

核心规格

Mythos-class 的全新基准：百万级上下文、128K 输出、ASL-3 安全等级。

共享底层模型：Fable 5 和 Mythos 5 使用完全相同的底层权重和基础模型。它们不是架构不同的模型——而是同一个模型用不同的安全配置打包。Mythos 5 是 Fable 5 的"无限制版本"，Fable 5 是 Mythos 5 的"安全封装版本"。

与传统安全策略的对比

传统AI模型面对敏感查询时通常采用"拒绝回答"的策略——直接返回一个拒绝信息。Fable 5 则采用了完全不同的方法：分类器驱动的动态路由。这种设计的精妙之处在于：用户不会收到令人沮丧的"我无法回答这个问题"，即使是敏感领域的查询，用户仍能获得 Opus 4.8 级别的回答。根据 Anthropic 数据，降级仅在 <5% 的会话中发生。

编程能力的质变级提升

编程能力是 Fable 5 / Mythos 5 最耀眼的领域。在多个权威编程基准上，它建立了令人瞩目的领先地位。 SWE-Bench Pro 是软件工程领域公认最困难的基准之一，测试模型在真实 GitHub 仓库中修复实际 Bug 的能力。Fable 5 的 80.3% 不仅刷新了纪录，更意味着它在超过八成的测试用例中成功完成了复杂的代码调试任务。

在 FrontierCode Diamond 上，Fable 5 以 29.3% 对 13.4% 的成绩，超过翻倍地击败了 Opus 4.8。这一差距极为显著，说明 Fable 5 在长程、多文件、生产级代码任务上拥有质变级的提升。

关键洞察：即使在中等投入条件下，Fable 5 的表现也超过了任何其他模型在任意投入条件下的成绩。这表明 Fable 5 在编程领域的优势并非来自"暴力计算"，而是来自架构层面的根本提升。

📝 关于带星号(*)基准的说明

带星号(*)的基准因 Fable 5 的安全护栏会出现降级到 Opus 4.8 的情况，表中显示的是 Mythos 5 的无限制成绩。对于 Fable 5 用户（公众模型），某些网络安全或生物相关查询可能触发降级。在大多数基准测试中，Fable 5 与 Mythos 5 的差距仅在 1-3 个百分点；在网络安全和生物相关基准上，差距可能扩大（因为 Fable 5 会降级到 Opus 4.8）。

📊 与 Claude Opus 4.8 的深度对比

Fable 5 相对于 Opus 4.8 的提升并非均匀分布，而是在特定领域呈现出"质的飞跃"。巨大领先领域（>10% 差距）包括：FrontierCode Diamond（29.3% vs 13.4%，+119% 相对提升）、SWE-Bench Pro（80.3% vs 69.2%，+16% 相对提升）、ExploitBench（78.0% vs 40.0%，+95% 相对提升）。中等领先领域（5-10% 差距）包括 Terminal-Bench、SWE-Bench Verified、CursorBench、HLE（with tools）。小幅领先领域（<5% 差距）包括 OSWorld-Verified 和 AutomationBench。

在长程记忆任务上，Fable 5 展现了惊人的改进。在 Slay the Spire 游戏基准（测试模型在长时间交互中保持状态的能力）中，Fable 5 相比 Opus 4.8 实现了 3 倍的性能提升——这种提升并非来自更好的游戏策略，而是来自模型在数百万 token 的交互历史中保持上下文连贯性的能力。

结论与选型建议

Fable 5 的发布标志着 Anthropic 正式进入 Mythos 时代。这个新的模型等级不仅代表了更高的性能基准，更引入了一种新的安全范式。

🔮 未来展望

Fable 5 的发布标志着 Anthropic 正式进入 Mythos 时代。这个新的模型等级不仅代表了更高的性能基准，更引入了一种新的安全范式——不是通过拒绝来保护，而是通过智能路由来平衡能力与安全。随着 Project Glasswing 的逐步扩展，我们或许会看到 Mythos 5 在更多领域的应用披露。而对于广大开发者来说，Fable 5 已经提供了足够强大的能力，足以重新定义我们对AI编码助手、研究伙伴和知识工作代理的期望。

🥇 选择 Claude Fable 5 如果你

  • 构建自主编程代理或代码审查系统
  • 需要最低的幻觉率（医疗/法律/金融）
  • 处理百万级 token 的文档分析
  • 预算允许为最高准确性支付溢价
  • 重视长程记忆和上下文连贯性

🥈 选择 GPT-5.5 如果你

  • 需要强大的 GUI 自动化能力
  • 优先纯科学推理能力
  • 已深度集成 OpenAI 生态
  • 能接受较高幻觉率并自行验证
  • 需要成熟的工具链支持

🥉 选择 Gemini 3.1 Pro 如果你

  • 处理大量输入且成本敏感
  • 优先原生视频/音频理解
  • 已在 Google Cloud 生态中
  • 追求最佳性价比平衡
  • 高吞吐量生产环境
